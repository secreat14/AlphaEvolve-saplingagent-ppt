Run the 47-term example

First, we load AlphaTensor’s published forty-seven terms. Each term has three lists: u selects entries from A, v selects from B, and w selects output cells. We combine the selected inputs, multiply once, and update the outputs modulo two.

Look at term two. Both input combinations give one, so the product is one. It updates two output cells, C one four and C two one. After all forty-seven terms, our result matches direct multiplication.

One example is not proof. We therefore check all four thousand and ninety-six coefficients. The notebook reports zero mismatches, so this rule works for any binary four-by-four inputs.

Compare the methods

Next, we compare methods. Direct multiplication uses sixty-four products. Strassen uses seven for a two-by-two matrix and applies that rule at two levels to get forty-nine. AlphaTensor uses forty-seven. All three pass the same coefficient check.

Show the cost graph

But fewer products can need more additions. In this simple model, the addition counts are forty-eight, three hundred and eighteen, and three hundred and forty. The graph changes the assumed cost of one multiplication. If multiplication costs one unit, Direct is cheapest. At twenty units, AlphaTensor is cheapest. These are modeled costs, not measured running times.
