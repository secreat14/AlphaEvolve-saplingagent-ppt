AI 如何发现更快的矩阵乘法

本项目交付一套约 14 分钟、16 页的中文交互式 HTML 演讲。内容从硬件基础进入矩阵乘法，再通过笔记本算例说明 Strassen、AlphaTensor、面向大矩阵的递归乘法量趋势和 AlphaEvolve 的算法发现与比较边界。

使用方式

  • 直接打开根目录 矩阵与AI-20分钟演讲.html，无需服务器。
  • 运行 Saplingagent 后，在当前主页面查看演讲，并通过右侧 AI 对话继续修改。
  • 运行 node scripts/build-presentation.mjs 从源码重新生成演讲。

项目结构

  • presentation/：模板、样式、动画和教学模型。
  • dist/：算法数据、静态教程和构建结果。
  • scripts/verify-*.mjs：数学与内容验证。
  • front/：Saplingagent 页面内嵌展示。
