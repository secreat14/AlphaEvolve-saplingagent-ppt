AI 如何发现更快的矩阵乘法

本项目交付一套约 18 分钟、21 页的中文交互式 HTML 演讲。内容从硬件基础进入矩阵乘法，再通过笔记本算例说明 Strassen，并用七页图解逐步说明 AlphaTensor 的输入组合、乘积复用、输出抵消、47 项回放、正确性与搜索，再讨论面向大矩阵的递归乘法量趋势和算法成本边界。

使用方式

仓库内课堂演讲 · 仓库内配音讲稿 · 仓库内 Demo Notebook

课堂提交主目录为上一级“演讲材料”。顶层有演讲与配音讲稿两份 HTML，以及 Demo 使用的 alphatensor_demo.ipynb。换设备时一起复制这三个文件。HTML 用浏览器打开，动画与正文音频均已内嵌，可离线使用。Notebook 用 Jupyter 或 VS Code 打开，选择 Python 3，安装 NumPy 和 Matplotlib 后从上到下运行。开发资料保留在 AlphaTensor演讲 子目录。

打开课堂演讲 · 打开课堂配音讲稿 · 下载 Demo Notebook

  • 直接打开根目录 矩阵与AI-20分钟演讲.html，无需服务器。
  • 运行 Saplingagent 后，在当前主页面查看演讲，并通过右侧 AI 对话继续修改。
  • 运行 node scripts/build-presentation.mjs 从源码重新生成演讲。

项目结构

  • presentation/：模板、样式、动画和教学模型。
  • dist/：算法数据、静态教程和构建结果。
  • scripts/verify-*.mjs：数学与内容验证。
  • front/：Saplingagent 页面内嵌展示。

论文与官方参考资料 · 接口说明

演讲页右上角可选择中文或 English，页面、动态说明和讲稿同时切换。按 N 打开对应语言的备注。浏览器记住选择，切换时保留当前页与动画状态，离线文件同样可用。

15 分钟中英对照讲稿对应当前 21 页，使用简单英语，附逐段中文、累计时间和演示提示。255 句正文均配有微软 Edge 神经语音，英文 Aria、中文晓晓，可逐句播放、全文连读、暂停继续、循环和变速，当前句自动高亮。音频内嵌，支持离线排练、阅读与打印。
